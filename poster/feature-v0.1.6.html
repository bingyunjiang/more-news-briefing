A briefing item, upgraded

一条新闻，不止一段摘要

高优先级
01
发生了什么

用来源支持的事实，交代事件本身。

02
为什么重要

指出它改变了什么、影响谁、为什么现在要看。

03
证据到什么程度

来源级别 + 证据状态；待确认内容不硬塞正文。

首选证据已确认2 个独立来源

The real difference

不是多一个功能，
是多一层判断责任。

事实、重要性、编辑判断和推断分别落位；读者能看懂“结论从哪里来”。

前置 · 合同定义范围与优先视角 后置 · 验收决定能否正式交付
不主张单项独占，强调组合后的闭环。
本期点评 / commentary

从多条新闻里，提炼本期真正变化的信号。

不是逐条夸一句，而是跨条目压缩成 1–3 个有区分度的判断。

认知延伸 / sprout

连接机制、先例、相邻领域与可观察情景。

必须写明依据，并标注“性质：推断”；不把预测伪装成事实。

继续跟踪 / continuity

把“还不知道”变成下期可执行的观察任务。

记录实体、指标、未决问题与时间范围；可导出显式 JSON，而非隐藏记忆。

验收门 / acceptance

缺证据、因果跳跃、反证未查，不静默放行。

阻断项会阻止正式 Markdown 写出；警告与证据缺口保留给操作者复核。

开放交付 / portable

结果不是锁在一次对话里的终点。

Markdown 可直接发送；continuity JSON 可交给下次运行或外部自动化。

One accountable loop

从“看完了”到“下期接着看”
