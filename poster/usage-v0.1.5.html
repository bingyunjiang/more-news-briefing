more news briefing

How to use · 03/03

From one prompt to delivery

一句话启动，
六步拿到可接续的简报。

第一次使用先选入口；之后可以按已确定的合同重复运行。

›

Step 01 · 在对话中调用

使用 $more-news-briefing，按默认主题做一个今日新闻简报。

02

选择首次入口

A · 直接开始按默认主题跑一版

B · 快速自定义只定四个关键字段

C · 深度自定义再加来源风格与观察名单

03

确定简报合同

主题组合AI / 政策 / 商业 / 专项

专项方向技术 / 公司 / 项目 / 市场

地域范围全球 / 中国 / 指定市场

优先视角政策 / 产品 / 标准 / 部署

深度自定义还可补：关键词、排除项、来源角色、公司/机构/社区观察名单。
04

让完整工作流自动运行

收集归一/去重排序/保留验证成稿认知验收润色

高影响条目优先验证；字段不全或证据不足的内容转入继续跟踪。

05

选择认知深度

compact默认；后台拷问，不展示扩展

insight本期点评 + 认知延伸

analyst / all再加继续跟踪与跨期状态

off纯摘要

06

验收并接收产物

daily-news-YYYY-MM-DD.md正式简报 · 默认 UTF-8 Markdown
continuity.json可选 · 下期追踪实体、指标、问题与时间范围

若存在阻断项，正式 Markdown 不会写出；警告、证据缺口和待跟踪条目保持可见。
